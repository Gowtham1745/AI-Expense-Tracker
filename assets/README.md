# Assets Directory

This directory contains optional profile photos for the creator and developer attribution in the sidebar.

## Required Files

Place the following files here (optional - the app shows initials-based avatars if missing):

- `keerthi.jpg` — Creator (Keerthi) profile photo
- `gowtham.jpg` — Developer (Gowtham A) profile photo

## Specifications

- **Format**: JPG or PNG
- **Recommended size**: 100x100 pixels (will be displayed at 36x36)
- **Aspect ratio**: 1:1 (square)
- **Style**: Professional headshot or clear photo

## Privacy Note

These images are only used locally in the sidebar attribution. They are:
- Not uploaded anywhere
- Not sent to any API
- Only displayed in the local Streamlit interface

If you don't want to include photos, simply leave this directory empty. The application will gracefully show initials-based avatars (K and G) instead.
